# «Команды» и «запросы» в SQL: в чём разница

Строгого стандарта, который бы жёстко закрепил эти термины, нет. Но в практике и документации сложилось устойчивое разделение. Разберём его.

---

## 🔹 1. Формальное деление по группам операторов

В SQL стандарт выделяет несколько групп операторов. Именно они чаще всего называются **командами**:

| Группа | Название | Операторы | Что делает |
|--------|----------|-----------|------------|
| **DQL** | Data Query Language | `SELECT` | **Читает** данные, возвращает результат |
| **DML** | Data Manipulation Language | `INSERT`, `UPDATE`, `DELETE` | **Изменяет** данные |
| **DDL** | Data Definition Language | `CREATE`, `ALTER`, `DROP`, `TRUNCATE`, `RENAME` | **Изменяет структуру** (таблицы, индексы, VIEW) |
| **DCL** | Data Control Language | `GRANT`, `REVOKE` | **Управляет доступом** |
| **TCL** | Transaction Control Language | `COMMIT`, `ROLLBACK`, `SAVEPOINT` | **Управляет транзакциями** |

**Отсюда простое правило:**

- **Запрос** — это `SELECT` (DQL). Он «спрашивает» данные и получает **набор строк** в ответ.
- **Команда** — это всё остальное: `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `DROP`, `GRANT` и т.д. Они **меняют состояние** базы и обычно не возвращают строк (только статус выполнения).

---

## 🔹 2. Как это выглядит на практике

| Действие | Что это | Возвращает ли строки? |
|----------|---------|------------------------|
| `SELECT * FROM customers;` | **Запрос** | ✅ Да, набор строк |
| `INSERT INTO customers ...;` | **Команда** | ❌ Нет, только `Query OK, 1 row affected` |
| `UPDATE customers SET ...;` | **Команда** | ❌ Нет, только `Rows matched: 1 Changed: 1` |
| `DELETE FROM customers ...;` | **Команда** | ❌ Нет, только `Query OK, 1 row affected` |
| `CREATE TABLE ...;` | **Команда** | ❌ Нет, только `Query OK, 0 rows affected` |
| `DROP TABLE ...;` | **Команда** | ❌ Нет |
| `GRANT ...;` | **Команда** | ❌ Нет |
| `COMMIT;` | **Команда** | ❌ Нет |

**Практический критерий:** если оператор возвращает **результат-таблицу** (строки и столбцы) — это **запрос**. Если только статус («выполнено», «затронуто строк») — это **команда**.

## 🔹 3. Где граница размывается

### 1. `INSERT ... RETURNING` (PostgreSQL) или `OUTPUT` (SQL Server)

В PostgreSQL можно написать:

```sql
INSERT INTO customers (name) VALUES ('Иван') RETURNING id, name;
```

Это **DML**, но он **возвращает строки**. Формально — команда, но ведёт себя как запрос. В MySQL такого нет (только `LAST_INSERT_ID()` отдельно).

### 2. `SHOW`, `USE`, `DESCRIBE` — клиентские команды, не SQL

В MySQL:

```sql
SHOW TABLES;
USE alias_db;
DESCRIBE customers;
```

Это **команды клиента `mysql`**, а не стандартный SQL. Сервер их понимает, но в стандарт они не входят. `SHOW` возвращает строки, но это не `SELECT`.

### 3. «Запрос» как синоним любого оператора

В документации MySQL **General Query Log** (общий журнал запросов) записывает **все** операторы — и `SELECT`, и `INSERT`, и `CREATE`. Там слово «query» используется в широком смысле: «любой оператор, отправленный серверу».

То же в `slow_query_log` — туда попадают не только `SELECT`, но и медленные `INSERT`/`UPDATE`.

Поэтому в контексте логов **«запрос» = любой SQL-оператор**.

## 🔹 4. Как употреблять в речи

| Контекст | Уместнее сказать | Пример |
|----------|------------------|--------|
| Чтение данных | **запрос** | «Напиши запрос, который вернёт клиентов из Москвы» |
| Изменение данных | **команда** | «Выполни команду `INSERT`» |
| Любой оператор в логе | **запрос** (широко) | «В general_log попали все запросы» |
| DDL | **команда** | «Команда `CREATE TABLE` создала файл `customers.ibd`» |
| `SELECT` | **запрос** | «Этот запрос возвращает 5 строк» |
| `UPDATE` | **команда** | «Команда `UPDATE` затронула 3 строки» |

**Итог:** в узком смысле **запрос = `SELECT`**, **команда = всё остальное**. В широком смысле «запрос» может означать любой оператор, особенно в логах и документации.

---

## 📌 Итог

| Термин | Узкий смысл | Широкий смысл |
|--------|-------------|----------------|
| **Запрос** | `SELECT` (DQL) — возвращает строки | Любой SQL-оператор, отправленный серверу (в логах) |
| **Команда** | `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `DROP`, `GRANT` и т.д. — меняют состояние | — |

**Практическое правило для повседневной работы:**

- Если оператор **возвращает таблицу** с данными → **запрос**.
- Если оператор **меняет данные или структуру** и возвращает только статус → **команда**.
