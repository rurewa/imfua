## Ретро-игра Doom/Freedoom

**Doom **— это не просто игра, а настоящий культурный феномен, который во многом определил облик современных видеоигр. Запустить её в Docker — отличный способ прикоснуться к классике и одновременно потренироваться в контейнеризации.

### Способ 1

Получить образ, создать и запустить контейнер
```shell
docker run --rm -it --shm-size=512m -p 6901:6901 -e VNC_PW=password kasmweb/doom:1.19.0
```
[После установки открыть в браузере этот адрес](https://localhost:6901/)

Логин: `kasm_user`
Пароль: `password`

### Способ 2

Клонируем репозиторий (если еще не сделали этого)
```shell
cd ~
git clone https://github.com/omarluq/doomcr.git
cd doomcr
```
Собираем Docker-образ
```shell
docker build -t doomcr:latest .
```

Для запуска **Freedoom** лучше использовать большой терминал, а то ничего не будет видно. Запуск с Freedoom:
```shell
docker run --rm -it -e DOOM_WAD_SOURCE=freedoom doomcr:latest
```
Эта команда создаст локальный образ с именем doomcr и тегом latest.

Чтобы выйти из игры достаточно выполнить **Ctrl+C**
